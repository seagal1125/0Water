## 2. 核心爭點 (Key Issues)

### 爭點一：修繕工法 (Local Repair vs. Full Redo)
- **建商方案**：局部挖開漏水點 -> 刮除表層 -> 塗防水 -> 貼磚。
    - **風險**：新舊防水層交接處（冷縫）因收縮率不同，地震後極易裂開；輕質灌漿牆內部孔隙多，水氣易導向未修補區域。
- **屋主訴求**：全室地壁磚剔除見底 -> 素地整平（含 R 角） -> 全室防水 -> 貼磚。
    - **依據**：確保防水層連續性，徹底解決素地不平與潛在漏水風險。

### 爭點二：素地整平 (Surface Leveling)
- **定義**：在塗防水層前，必須將結構牆表面的坑洞、凸起、粉塵完全清除，並用水泥砂漿抹平。
- **重要性**：若素地不平（有尖銳物或粉塵），防水層會被刺破或無法附著（膨管）。
- **判決支持**：法院判決中明確要求「施作地面水泥砂漿打底墊高」，隱含必須將舊防水層完全剔除。

### 爭點三：輕質灌漿牆 (Lightweight Grouted Wall)
- **特性**：內部含有保麗龍球或輕質骨材，結構較疏鬆。
- **漏水風險**：水氣容易在牆體內部亂竄（非單一路徑）。
- **修繕建議**：若發生漏水，強烈建議整面牆重做，甚至拆除受潮的表面板材（如矽酸鈣板）。

## 3. 法律資源與判決 (Legal Resources & Judgments)

> [!TIP]
> 詳細判決內容與分析請見 [judgments.json](judgments.json)

### 關鍵判決：臺灣桃園地方法院 112年度訴字第553號
- **案例摘要**：5樓浴室漏水致4樓受損，法院判決5樓屋主需容忍修繕並負擔費用。
- **法院認證工法**：
    1.  **拆除範圍**：拆除地壁磚至輕鋼架層（全室高度）。
    2.  **素地處理**：施作地面水泥砂漿打底墊高（含止水墩）。
    3.  **防水範圍**：塗刷防水塗料 6.5 坪（全室地壁，非局部）。
- **應用策略**：此判決證明「打掉重做」是法院認可的標準修繕工法，非屋主無理要求。

## 4. 溝通策略 (Communication Strategy)

### 策略原則
- **態度**：有禮貌但立場強硬 (Polite but Firm)。
- **行動**：先發 LINE 通知 -> 存證信函 -> 消保官申訴 -> 訴訟。
- **底線**：不接受 5 萬元保留款（違法條款），堅持 137 萬元（法定 5%）。

### 實用話術範本

#### 針對「局部修補」的回應
> 「工務承認這是『輕質灌漿牆』，且僅做局部挖開。諮詢專業意見後，局部修補會產生新舊防水層接縫（冷縫）風險，且無法解決牆體內水氣亂竄問題。我堅持比照法院判決標準，進行全室地壁磚剔除見底及防水重做，以確保房屋耐用度。」

#### 針對「保留款」的回應
> 「依據內政部《預售屋買賣定型化契約應記載及不得記載事項》第13點，買方得保留房地總價 5% 作為交屋保留款。貴司合約之 5 萬元條款已違反法令無效。在防水瑕疵完全修復前，本人將依法主張保留 137 萬元款項。」

### 存證信函重點
1.  **主旨**：針對交屋保留款及修繕爭議之異議。
2.  **事實**：浴室防水工程有重大瑕疵（素地未整平、防水層不連續）。
3.  **主張**：引用內政部規定，保留 5% 價金（137 萬元）。
4.  **要求**：限期提出符合標準（全室重做）的修繕計畫。
